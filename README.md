# こよみ日和

家族向け年間イベントカレンダーの静的Webアプリです。GitHub Pagesで動作します。

- 「興味なし」はEvents.not_interestedとしてイベント全体に保存し、全年度のカレンダーとアプリ内検索から除外します。設定の一覧から解除できます。旧skipは無視して保持します。外部の候補収集も、この列がTRUEのevent_idを除外し、この列を保持してください。
- デモは架空のイベントです。デモ選択は端末に保存します。
- 本番データは、本人がGoogleで許可した非公開Google Sheetsから直接取得・保存します。
- Googleの短期トークンはブラウザーのメモリだけで保持します。閉じる・再読み込み・期限切れの際は再接続が必要です。
- サービスアカウントのJSON秘密鍵、クライアントシークレット、更新トークンを使いません。
- 公開コードに実イベントの取得結果や個人のSheets ID・出発地点は含めません。
- 初期状態のGoogleアプリ識別子は未設定です。Google接続の実動作は設定・本人の許可後に検証します。
- Googleの設定はsite-config.jsの公開識別子だけ。機密情報を入れないでください。
- GitHub Pagesはリポジトリのmainブランチ・ルートから配信します。
- ソースは公開ですが、SheetsデータはGoogleの共有権限で保護されます。
- 同じ項目の同時更新は後の状態が残るため、端末間の厳密な排他を保証しません。初回操作の同時登録で複数行になった場合は、項目単位で統合して表示します。既存行の削除は行いません。
- シートの行順変更や外部更新が保存と重なった場合は、読戻し検証で競合を報告します。
- GitHub Pagesを使うための有料契約や独自ドメインは不要です。Google APIは利用枠内で運用します。
